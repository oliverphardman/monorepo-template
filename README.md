# monorepo-template

Standard template used for new repos.

> [!IMPORTANT]
> After cloning, run this once to enable the Git hooks:
>
> ```sh
> git config core.hooksPath .githooks
> ```

## Included

### Git hooks (`.githooks/`)

A plain-shell `pre-commit` hook. It checks staged changes for whitespace errors and conflict markers, then runs:

- **Terraform**, in each directory with staged `.tf` / `.tfvars` files: `init -backend=false`, `validate` and `fmt -check`. Requires `terraform`.
- **Node apps**, in each `apps/*` directory with staged changes and a `package.json`: `pnpm run lint`, `test` and `format`. Scripts that aren't defined are skipped. Requires `pnpm`.

Enable it with the command above. `git commit --no-verify` bypasses it, so CI should enforce the same checks.

### GitHub Actions (`.github/workflows/`)

All workflows ship disabled (`.disabledyml`). Rename a file to `.yml` to enable it. They use `pnpm` and run on a self-hosted runner.

| Workflow | Purpose |
| --- | --- |
| `ci` | Typecheck, format check, test and build for the API, web and Android apps |
| `deploy-dev` | Deploys infrastructure and apps to the Development environment |
| `release` | Builds and deploys to Production from a release tag |
| `release-please` | Opens release PRs and changelogs from conventional commits |
| `trivy` | Security scan |

### Dependency updates (`.github/dependabot.yml`)

Weekly Dependabot updates for GitHub Actions are enabled. Blocks for npm, Gradle and Terraform are included but commented out; uncomment the ones you need.

### Releases

`release-please-config.json` and `.release-please-manifest.json` configure release-please, including changelog sections for conventional commit types. The package entry is commented out until you add your apps.

### Community files

- `CONTRIBUTING.md`: setup, workflow and commit conventions
- `CODE_OF_CONDUCT.md`: expected behaviour and reporting
- `CHANGELOG.md`: generated by release-please
- `.github/pull_request_template.md`: PR checklist
- `.github/ISSUE_TEMPLATE/`: bug report and feature request forms (blank issues disabled)

### Repository layout

- `apps/`: application code (empty, with an `example/` placeholder)
- `infra/`: Terraform
- `AGENTS.md`: guidance for AI coding agents (currently a stub)

### Editor and housekeeping

- `.editorconfig`: indentation, line endings and charset
- `.vscode/`: recommended extensions and workspace settings
- `.gitignore`
- `SECURITY.md`: security policy
- `LICENSE`
